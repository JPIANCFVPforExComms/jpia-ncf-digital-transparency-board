# JPIA-NCF Digital Transparency Board

This repository contains the source files for the JPIA-NCF Chapter Digital Transparency Board.

Files:
- index.html — loader page that fetches the full HTML from `JPIA DIGITAL TRANSPARENCY BOARD.txt`
- JPIA DIGITAL TRANSPARENCY BOARD.txt — the full site HTML to be served by GitHub Pages

To publish updates:
1. Edit `JPIA DIGITAL TRANSPARENCY BOARD.txt` directly or via a branch + pull request.
2. Add `documents/` files (PDFs) and update the `docs` array in the site HTML.

Notes:
- The repository is public. Do not add secrets or personal data.
